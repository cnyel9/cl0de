Cl0de 0.0.1 tester5 adalah rilis perbaikan dari hasil uji perangkat tester4: chat Deep yang gagal total, teks banner Deep yang terpotong, dan belum adanya panduan pemulihan server di dalam aplikasi.

## Isi rilis

- Perbaikan chat Deep: layanan DeepChat menolak systemPrompt yang lebih panjang dari 4.000 karakter, dan gabungan teks system dari OpenCode (prompt agen, konteks lingkungan, AGENTS.md) hampir selalu melewati batas itu, sehingga semua chat Deep di tester4 berakhir dengan error HTTP 400. Bridge Deep kini memangkas teks system gabungan ke maksimum 4.000 karakter dengan mempertahankan bagian depan (prompt agen yang terpenting ada di depan; yang terpotong adalah ekor konteks sesudahnya), dan mencatat pemangkasan itu di log bridge. Pemetaan lain tidak berubah: riwayat, gambar, dan batas waktu tetap seperti tester4.
- Banner Deep tampil penuh: teks info "Model Deep hanya untuk chat sehari hari, bukan agen" di layar chat tidak lagi terpotong elipsis. Teksnya kini membungkus ke sebanyak baris yang dibutuhkan sampai habis, supaya benar benar terbaca. Cara tampil, tombol tutup, dan aturan muncul lagi sesudah ditutup tidak berubah.
- Kartu pemulihan server di layar Server lokal: tepat di bawah grup pengaturan server kini ada kartu "Server crash atau tidak mau menyala?" berisi alur lima langkah bernomor: stop server jika sedang berjalan, pergi ke Info Aplikasi Cl0de, Hapus Cache, Paksa Berhenti, lalu jalankan servernya lagi. Di bawah alur ada tombol Buka Info Aplikasi yang membuka halaman Info Aplikasi Cl0de langsung, dengan arahan manual lewat toast bila halaman itu tidak bisa dibuka.

Catatan jujur: pemangkasan systemPrompt berarti untuk chat Deep, bagian paling belakang dari konteks system (sebagian konteks lingkungan dan ekor AGENTS.md yang panjang) tidak ikut terkirim ke model; prompt agennya sendiri selalu utuh karena berada di depan. Ini batas dari layanan DeepChat, bukan pilihan desain. Kartu pemulihan server adalah panduan langkah manual, bukan perbaikan otomatis: penyebab crash yang paling sering adalah proses server lama yang masih memegang port, dan langkah langkah itu yang membersihkannya.

## Pasang

Pasang APK ini menimpa pemasangan sebelumnya, tidak perlu copot pasang, karena sertifikatnya sama dengan release-1. Paket com.cl0de.app, versi 0.0.1 tester5, versionCode 12. Ukuran dan md5 APK menyusul di catatan rilis GitHub sesudah build selesai, tidak ditulis di berkas ini.
