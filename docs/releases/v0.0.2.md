Cl0de 0.0.2 adalah rilis resmi pertama sesudah 0.0.1 release-1, menutup garis pengujian 0.0.1 (tester1 sampai tester7) yang seluruhnya sudah lulus uji perangkat. Rilis ini merangkum semua yang dibangun selama garis pengujian itu: model offline yang bisa dipakai tanpa jaringan, provider Deep dengan 16 model chat, dan gambar yang akhirnya berfungsi untuk semua model Deep.

## Isi rilis

- Model offline: katalog 20 model lokal mengikuti katalog Android PocketPal, berjalan di perangkat lewat server lokal. Agen offline ditegakkan tanpa tool di gerbang kirim (penegakan berlaku juga untuk sesi lama yang dilanjutkan, bukan hanya saat memilih model), jadi model lokal berperan sebagai chat cadangan offline di perangkat, bukan sebagai agen.
- Provider Deep (baru): 16 model chat dari layanan DeepChat (GPT, Claude, Gemini, DeepSeek, Kimi, Grok, Mistral, Sonar) diakses lewat bridge lokal di perangkat yang membungkus modul DeepChat apa adanya. Model bawaan untuk pemasangan baru adalah Claude Opus 4.7. Di picker, model Deep berlabel "(Chat)" dan ada banner info yang menyatakan model Deep hanya untuk chat sehari hari, bukan agen; sesi Deep berjalan dengan agen ringan khusus Deep tanpa tool, dan beralih ke provider lain memulihkan agen bertool seperti semula.
- Gambar untuk semua model Deep: 6 model vision (GPT-4o Mini, GPT-4.1, Claude Haiku 4.5, Claude Opus 4.7, Gemini 2.5 Pro, Kimi K3) membaca gambar yang dilampirkan secara langsung, termasuk gambar dari pesan sebelumnya dalam jendela beberapa giliran. 10 model teks menerima gambar lewat relay: gambar dideskripsikan dulu oleh GPT-4o Mini (deskripsi maksimum sekitar 1.000 karakter) lalu deskripsinya diteruskan sebagai teks ke model tujuan, dengan cache per gambar supaya gambar yang sama tidak dideskripsikan berulang. Penutup sub-bagian ini adalah perbaikan akar di tester7: registrasi model Deep kini mendeklarasikan attachment dan modalities untuk semua 16 model, karena tanpa deklarasi itu OpenCode membuang lampiran gambar untuk provider kustom sebelum request dibuat, dan tidak ada model Deep yang pernah menerima gambar dari aplikasi.
- Kredit Deep terisi otomatis: saat chat Deep kena batas kredit (HTTP 402), bridge mengklaim kredit dari layanan dan mengulang chat itu sekali secara otomatis, sehingga percakapan berlanjut tanpa pengguna mengirim ulang. Bila isi ulang menyerah (klaim gagal beruntun atau jatah klaim sesi habis), error asli dari layanan diteruskan apa adanya ke pengguna.
- Memory untuk Deep: ringkasan memory ringkas (aturan pengguna dari preferensi profil ditambah baris fakta memory, pagu total sekitar 1.500 karakter) diselipkan ke system prompt pada posisi aman, tepat sesudah prompt agen, supaya tidak gugur oleh pemangkasan system prompt ke maksimum 4.000 karakter yang diberlakukan DeepChat. Blok ini hanya hidup di request model Deep, tidak disimpan ke config dan tidak mengubah AGENTS.md.
- Kartu pemulihan server lokal di layar Server: alur 5 langkah tersambung (Stop server, Info Aplikasi Cl0de, Hapus Cache, Paksa Berhenti, Jalankan lagi) dengan tombol yang membuka Info Aplikasi Cl0de di Pengaturan Android, untuk memulihkan keadaan server lokal yang macet tanpa menebak nebak.
- Picker "Model lain": urutan provider sekarang Deep paling atas, lalu OpenCode bawaan, lalu provider kustom. Pencarian model mencocokkan nama provider juga, bukan hanya nama model (mengetik "Deep" menampilkan semua model Deep), dan baris model dibuat kompak.
- Pil model di header chat kini menampilkan nama provider yang sedang aktif (misalnya "Deep"), bukan lagi teks keras "OpenCode" untuk semua provider.
- Profil: editor preferensi (aturan pengguna) yang panjang bisa diciutkan supaya tidak memaksa gulir jauh, dan preferensi bisa diimpor dari berkas .md atau .zip (di dalam zip dicari berkas AGENTS.md di kedalaman mana pun); hasil impor mengisi editor dan baru tersimpan lewat tombol Simpan seperti biasa.

Catatan jujur: model Deep bergantung pada layanan DeepChat pihak ketiga beserta sesi dan jatah kreditnya, bukan layanan kami, jadi ketersediaan dan perilakunya berada di luar kendali aplikasi; model Deep adalah model chat saja tanpa tool calling, mereka tidak bisa menjalankan perintah, menyentuh berkas, atau memakai MCP. Untuk 10 model teks, relay adalah deskripsi buatan model vision, bukan penglihatan langsung, jadi detail di luar deskripsi tidak diketahui model tujuan. Server hulu sesekali tidak stabil; selama pengujian Kimi K3 pernah membalas HTTP 500 internal_error pada sebagian kiriman sementara model lain normal. Pesan error 402 mentah masih bisa muncul pada jalur isi ulang yang menyerah, walau pada pengujian jalur otomatisnya terbukti menolong sebagian besar kasus. Model offline adalah chat cadangan dengan konteks kecil; ia tidak dirancang menjalankan tugas agen.

## Pasang

Pasang APK ini menimpa pemasangan sebelumnya, tidak perlu copot pasang, karena sertifikatnya sama dengan release-1 dan semua tester. Paket com.cl0de.app, versi 0.0.2, versionCode 16. Ukuran dan md5 APK menyusul di catatan rilis GitHub sesudah build selesai, tidak ditulis di berkas ini.
