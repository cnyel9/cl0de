Cl0de 0.0.1 tester3 membawa fitur besar baru bernama Model Offline: menjalankan model AI langsung di HP tanpa internet. Rilis ini adalah hasil tiga gelombang pengujian (tester1 sampai tester3) dan sudah dinyatakan aman di perangkat pengujian Redmi 14C.

## Isi rilis

- Model Offline: model AI berjalan langsung di HP, tanpa internet, sesudah modelnya diunduh sekali.
- Mesin llama.cpp diunduh terpisah sebagai komponen (sekitar 19 MB, sekali saja), jadi ukuran APK tidak membengkak dan tidak ada berkas model di dalam APK.
- Layar khusus Model Offline, pintu masuk dari Pengaturan dan dari pemilih model.
- Katalog 20 model dengan deskripsi keunggulan per model. Pilihan menyesuaikan RAM HP: di bawah 8 GB ditawari 11 model, 8 GB ke atas ditawari 12 model (3 model tampil di kedua kelas). Tiap kartu menampilkan total ukuran unduhan dan RAM minimum; model vision mengunduh berkas pendamping sekaligus dan total ukurannya sudah gabungan.
- Unduhan model tampil progresnya di kartu (terunduh dari total, plus persen), bisa diteruskan dari posisi terakhir bila putus dan mencoba lagi sendiri; unduhan yang gagal total dibersihkan otomatis dari penyimpanan.
- Model terunduh muncul di pemilih model biasa dengan akhiran (Offline). Memilihnya menyalakan server lokalnya sendiri, tidak ada yang perlu dinyalakan manual. Beralih ke model online atau aplikasi pindah ke latar belakang melepas model dari RAM.
- Panel status di layar Model Offline: keadaan server lokal beserta model yang berjalan, dan RAM perangkat beserta kelasnya, plus tombol Matikan server lokal.
- Tes Kecepatan per model terunduh (llama-bench), hasilnya tersimpan di kartu model itu. Di Redmi 14C, Qwen3 0.6B terukur menulis 5,95 token per detik.
- Mode chat ringan khusus offline: agent tanpa alat tambahan dan prompt pendek, otomatis aktif saat model offline dipakai dan otomatis kembali normal saat beralih ke model online, termasuk pada sesi lama yang dilanjutkan.

## Perbaikan di tester3

- Chat offline sekarang menjawab, termasuk di sesi lama yang dilanjutkan. Akar masalahnya berlapis: di tester1 permintaan bawaan sesi OpenCode sebesar 17.560 token mental di kapasitas model lokal 4.096 token; tester2 menambahkan mode chat ringan tetapi pengaktifannya terikat aksi memilih model sehingga sesi lanjutan tetap gagal (15.247 token); tester3 menegakkan mode ringan itu di gerbang kirim berdasarkan model yang sedang aktif. Pengukuran laboratorium memastikan mode ringan yang benar benar aktif hanya mengirim sekitar 144 token.
- Server lokal berjalan satu slot: kecepatan menulis chat naik dari sekitar 2,2 menjadi sekitar 5,95 token per detik pada model yang sama.
- Kartu Model Offline responsif: baris tombol tidak lagi terjepit saat status Tes Kecepatan tampil, chip hasil kecepatan tampil utuh di dalam kartu, dan tombol Hapus kini ikon tempat sampah saja tanpa teks.
- Urutan cara cadangan menjalankan mesin lokal selalu dicoba lengkap dari awal bila cara yang teringat gagal, untuk chat maupun Tes Kecepatan.
- Server lokal berhenti otomatis saat beralih ke model online lewat jalur mana pun, dan saat beralih ke perangkat remote, membebaskan sekitar 1,4 GB RAM.
- Pembersihan unduhan yang gagal total kini menghapus juga berkas utama model yang mengunduh dua berkas, dengan pengecualian berkas pendamping yang dipakai bersama model lain yang sudah utuh.
- Catatan kematian server lokal kini satu baris lengkap: kode keluar, lama berjalan, keadaan pemeriksaan kesehatan, model, cara jalan, dan tindakan berikutnya.
- Dua pesan kegagalan server lokal yang sebelumnya tampil mentah dalam Bahasa Inggris kini mengikuti bahasa aplikasi.

Catatan jujur: mode offline di rilis ini adalah chat cadangan tanpa alat, bukan agen penuh. Model yang lebih besar menjawab lebih lambat di HP bertenaga kecil; pakai Tes Kecepatan untuk mengetahui kecepatan model pilihanmu di HP kamu. Unduhan mesin dan model tetap memerlukan internet satu kali; yang berjalan tanpa internet adalah chat nya. Model offline belum menerima lampiran gambar di chat.
