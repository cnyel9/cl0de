Cl0de 0.0.1 tester6 adalah rilis lanjutan dari hasil uji perangkat tester5: kredit Deep yang habis di tengah chat, gambar yang tidak terbaca model Deep, daftar model yang urutan dan pencariannya belum sesuai, label provider di header, editor preferensi yang memanjang, dan model Deep yang tidak membaca memory pengguna.

## Isi rilis

- Isi kredit otomatis untuk chat Deep: bila layanan DeepChat menolak kiriman karena kredit tidak cukup (HTTP 402), bridge kini mengklaim kredit beberapa kali dalam jendela sekitar 6 detik (modul bawaan sudah mengklaim dan mencoba sekali di dalamnya; ini lapisan kedua sesudahnya), lalu mengulang chat satu kali secara otomatis. Error mentah 402 tidak lagi muncul untuk kekurangan kredit yang bisa ditambal; bila klaim gagal berturut turut, jatah klaim harian habis, atau saldo tetap kurang sesudah pengulangan, error aslinya diteruskan apa adanya.
- Gambar terbaca semua model Deep: bridge menerima bentuk lampiran yang sebenarnya dikirim aplikasi (part berkas bergambar, selain bentuk image_url), mencari gambar terbaru dalam tiga giliran terakhir (jadi pertanyaan lanjutan seperti "gambar apa itu" tetap membawa gambarnya), dan menerapkan pagar ketat: hanya data URL bergambar jpeg/png/webp/gif dalam batas ukuran. Untuk model yang memang bisa melihat (6 model), gambar diteruskan seperti sebelumnya. Untuk model teks (10 model), gambar dideskripsikan dulu oleh model vision GPT-4o Mini dan deskripsinya disisipkan sebagai teks di depan pesan, dengan cache supaya gambar yang sama tidak dideskripsikan berulang.
- Model Deep membaca ringkasan memory: aplikasi menyusun blok padat (preferensi Profil lebih dulu, lalu fakta memory per baris, maksimum sekitar 1.500 karakter) dan bridge mengangkatnya tepat sesudah prompt agen di dalam system prompt, sebelum pemangkasan 4.000 karakter berlaku. Sesi anonim tidak menerima blok ini.
- Daftar model dirapikan: provider Deep kini selalu paling atas, disusul OpenCode, lalu provider lain. Pencarian di halaman Model lain juga mencocokkan nama provider (mengetik "deep" menemukan semua model Deep dan juga DeepSeek). Baris model di halaman itu dibuat kompak. Default model untuk pasang baru diganti menjadi Deep Claude Opus 4.7 (pengguna lama tidak ikut berpindah).
- Pil model di header kini menampilkan nama provider yang sedang dipakai (misalnya Deep), bukan teks OpenCode terus, dan nama model tidak lagi membawa akhiran (Chat).
- Preferensi di Profil bisa dilipat dan diimpor: aturan yang panjang mulai tampil ringkas sebagai pratinjau dengan tombol Ubah preferensi, dan tombol Simpan ditahan selama terlipat. Preferensi kini bisa diimpor dari berkas .md atau .zip (di dalam zip yang dicari adalah AGENTS.md); hasil impor mengisi editor dan belum tersimpan, jadi selalu bisa diperiksa dulu sebelum menekan Simpan.

Catatan jujur: relay untuk model teks adalah deskripsi buatan model vision, bukan penglihatan langsung; model teks menjawab berdasarkan deskripsi itu, jadi detail yang tidak masuk deskripsi (maksimum sekitar 1.000 karakter) tidak akan diketahui model. Ringkasan memory adalah potongan inti (preferensi dan fakta teratas dalam pagu sekitar 1.500 karakter), bukan seluruh memory; memory lengkap tetap hanya terbaca model bertool lewat AGENTS.md seperti sebelumnya. Isi kredit otomatis menambah jeda beberapa detik pada chat yang kena 402 (klaim berjalan beberapa kali dulu), dan klaim tetap tunduk pada jatah harian layanan DeepChat, jadi model mahal dalam sesi panjang tetap bisa kehabisan kredit betulan. Pemangkasan systemPrompt 4.000 karakter dari tester5 tetap berlaku untuk sisa konteks sesudah prompt agen dan blok memory.

## Pasang

Pasang APK ini menimpa pemasangan sebelumnya, tidak perlu copot pasang, karena sertifikatnya sama dengan release-1. Paket com.cl0de.app, versi 0.0.1 tester6, versionCode 13. Ukuran dan md5 APK menyusul di catatan rilis GitHub sesudah build selesai, tidak ditulis di berkas ini.
