Cl0de 0.0.1 tester7 adalah rilis perbaikan tunggal dari hasil uji perangkat tester6: gambar yang dikirim ke model Deep tidak pernah sampai ke modelnya. Keenam model yang seharusnya bisa melihat gambar menjawab seolah tidak ada gambar, dan satu model bahkan mengarang isi gambarnya.

## Isi rilis

- Akar masalahnya ada di registrasi model, bukan di bridge: log bridge di perangkat membuktikan request yang tiba hanya berisi teks (parts=[text]) untuk semua model Deep. Untuk provider kustom, OpenCode tidak menemukan kemampuan model dari daftar modelnya; tanpa deklarasi modalities di config, model dianggap teks saja dan lampiran gambar dibuang diam diam sebelum request dibuat, sedangkan nama berkasnya disisakan sebagai teks (itu sebabnya satu model tahu nama berkasnya tetapi tidak tahu isinya). Registrasi model Deep kini mendeklarasikan attachment dan modalities (input text dan image, output text) untuk semua 16 model.
- Hasilnya: 6 model yang memang bisa melihat (GPT-4o Mini, GPT-4.1, Claude Haiku 4.5, Claude Opus 4.7, Gemini 2.5 Pro, Kimi K3) kini menerima gambarnya langsung. 10 model teks menerima gambar lewat relay deskripsi GPT-4o Mini yang dibangun di tester6; jalur relay itu sudah ada sejak tester6 tetapi tidak pernah terpicu dari aplikasi karena gambarnya selalu dibuang di hulu.
- Pemasangan lama ikut diperbaiki otomatis, tanpa copot pasang dan tanpa hapus data: registrasi provider berjalan lagi setiap server mencapai status Running pada start aplikasi (penanda synced hanya hidup di memori proses, jadi selalu mulai dari belum sinkron sesudah aplikasi dimulai ulang), dan patch config server bersifat deep merge, jadi deklarasi modalities tertambah ke entri model yang sudah ada di opencode.jsonc dan nilai attachment yang lama tertimpa, tanpa menghapus kunci apa pun.

Catatan jujur: deklarasi kemampuan gambar untuk model teks adalah kesengajaan, supaya OpenCode meneruskan lampirannya ke bridge; yang memilah gambar mentah versus deskripsi tetap bridge berdasarkan katalog layanan DeepChat sendiri, bukan OpenCode. Relay tetap berupa deskripsi buatan model vision (maksimum sekitar 1.000 karakter), bukan penglihatan langsung, jadi model teks tetap tidak mengetahui detail di luar deskripsi itu. Perbaikan ini menyasar akar yang terbukti dari log bridge perangkat tester6; vonis akhirnya tetap ditentukan uji perangkat sesudah tester7 terpasang, dengan foto yang sama ke model vision dan ke model teks.

## Pasang

Pasang APK ini menimpa pemasangan sebelumnya, tidak perlu copot pasang, karena sertifikatnya sama dengan release-1. Paket com.cl0de.app, versi 0.0.1 tester7, versionCode 14. Ukuran dan md5 APK menyusul di catatan rilis GitHub sesudah build selesai, tidak ditulis di berkas ini.
