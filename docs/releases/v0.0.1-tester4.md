Cl0de 0.0.1 tester4 membawa provider baru bernama Deep: 16 model chat dari layanan DeepChat, tersedia langsung di pemilih model dan menjadi model bawaan pada pemasangan baru. Deep adalah provider chat saja, bukan agen.

## Isi rilis

- Provider Deep: 16 model chat tampil di pemilih model dengan akhiran (Chat), misalnya GPT-4o Mini (Chat). Enam model di antaranya menerima lampiran gambar: GPT-4o Mini, GPT-4.1, Claude Haiku 4.5, Claude Opus 4.7, Gemini 2.5 Pro, dan Kimi K3. Model tetap tampil di pemilih walau layanan penghubungnya belum menyala; ia dinyalakan otomatis saat pertama dipakai.
- Model bawaan pemasangan baru: GPT-4o Mini (Chat) dari provider Deep, jadi aplikasi yang baru dipasang bisa langsung dipakai chat tanpa menyiapkan akun atau kunci apa pun. Pemasangan lama tidak berubah sama sekali: provider Deep muncul di pemilih, tetapi model yang sedang terpilih tetap seperti sebelumnya.
- Layanan penghubung (bridge) berjalan lokal di dalam lingkungan aplikasi, membungkus modul DeepChat yang dibundel utuh tanpa diubah satu byte pun (sha256 modul terpaku dan diverifikasi setiap kali disalin ke lingkungan). Karena lingkungan aplikasi tidak memasang runtime JavaScript, Node.js dipasang sekali lewat apt saat Deep pertama kali dipakai, atau sekalian lewat menu Pasang alat dev di Pengaturan.
- Mode chat ringan khusus Deep: agent tanpa alat dan prompt pendek, otomatis aktif saat model Deep dipakai dan otomatis kembali ke agent biasa saat beralih ke model bertool, termasuk pada sesi lama yang dilanjutkan dan perpindahan langsung dari atau ke model offline.
- Banner info tipis di layar chat selama model Deep aktif, menyatakan model Deep hanya untuk chat sehari hari dan bukan agen. Bisa ditutup dengan tombol X; sesudah ditutup ia tidak muncul lagi selama pilihan tetap di provider Deep, dan baru tampil lagi bila pilihan sempat meninggalkan Deep lalu kembali, atau aplikasi dibuka ulang.
- Layanan penghubung tidak dimatikan saat beralih ke model lain atau aplikasi ke latar belakang, supaya sesinya tetap hidup. Ia hanya berhenti saat runtime direset atau aplikasi dihentikan.

## Yang baru di tester4

- Gerbang kirim kini menegakkan agent dan layanan lokal dari potret pilihan model saat kirim dimulai: bila model diganti saat penegakan sedang menunggu, kirim dibatalkan dengan pesan yang jelas alih alih terkirim dengan campuran dua model.
- Satu keputusan sesudah memilih model untuk semua jalur (pemilih model, pilihan otomatis katalog, aktivasi model gratis, layar Model Offline), menggantikan logika yang tersebar. Perpindahan ke perangkat remote kini juga memulihkan agent pengguna, menutup celah lama di mana agent ringan lokal bisa terbawa ke server remote.
- Pemutusan provider Deep dari layar Providers kini benar benar mencabutnya, mengikuti pola per provider yang ada.

Catatan jujur: Deep adalah provider CHAT SAJA. Model Deep tidak bisa menjalankan alat, membuka berkas, atau menjalankan perintah, jadi bukan pengganti agent untuk pekerjaan. Deep menumpang layanan aplikasi DeepChat lewat modul yang dibundel: sesi yang dipakai adalah sesi anonim yang dibuat modul itu sendiri, dan kredit chat berasal dari klaim reward iklan otomatis di dalam modul, bukan dari akun DeepChat milikmu. Karena itu ada batas pemakaian per sesi dan sesi hidup di memori layanan penghubung; bila layanan itu dimulai ulang, sesi baru dibuat dan jatah klaim mulai lagi dari awal. Nama model mengikuti katalog DeepChat, tetapi identitas model sebenarnya di balik nama itu tidak bisa diverifikasi dari luar. Angka biaya kredit di katalog sumber juga bukan janji potongan sebenarnya: pengukuran kami menemukan model yang katalognya menulis biaya 1 ternyata terpotong 0. Satu model teks yang diiklankan bahan sumbernya, deepseek-reasoner, tidak ikut didaftarkan karena katalog layanannya sendiri menandainya nonaktif.

## Pasang
