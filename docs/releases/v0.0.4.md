Cl0de 0.0.4 adalah rilis resmi sesudah 0.0.3, menutup garis pengujian 0.0.4 test. Isi utamanya provider MiMo yang kini resmi, ditambah dua perbaikan keandalan: DNS lingkungan yang dijaga tetap utuh, dan pemeriksaan kesehatan sambungan GitHub dengan tombol perbaiki.

## Isi rilis

- Provider MiMo (resmi, sebelumnya build uji 0.0.4 test): empat model chat Xiaomi MiMo Studio masuk picker sebagai provider "MiMo", tepat sesudah Deep: MiMo V2.6 Pro, MiMo V2.6 Flash, MiMo V2.5 Pro, dan MiMo V2.5, semuanya berlabel "(Chat)". Di baliknya ada bridge lokal (Node.js, port 8182, proses terpisah dari bridge Deep) yang membungkus modul MiMo Studio pihak ketiga yang dibundel utuh tanpa diubah, persis pola provider Deep. MiMo adalah chat saja: tanpa tool (agen ringan "mimo" sendiri), tanpa gambar, dan web search-nya tidak dinyalakan. Semua pemasangan langsung bisa memakai MiMo tanpa login apa pun karena cookie sesi MiMo Studio ditanam ke APK saat build dari secret repo; cookie tidak pernah masuk config OpenCode atau prefs. Default pasang baru tidak berubah: tetap model Deep.
- DNS lingkungan dijaga tetap utuh: berkas /etc/resolv.conf di dalam Ubuntu kini diperiksa dan ditegakkan kembali setiap proses lingkungan mulai (server, perintah sekali jalan, dan bridge), isinya tepat tiga nameserver publik 1.1.1.1, 8.8.8.8, dan 9.9.9.9 sebagai cadangan ketiga. Sebelumnya berkas itu hanya ditulis sekali saat pemasangan pertama, jadi bila isinya berubah atau rusak di dalam lingkungan, tidak ada yang memulihkannya.
- Pemeriksaan kesehatan sambungan GitHub: layar GitHub kini menampilkan baris "Status sambungan" yang memeriksa keadaan sebenarnya di dalam lingkungan, bukan sekadar bendera masuk di aplikasi. Pemeriksaan membedakan: terhubung sehat (gh menjawab, helper kredensial git menunjuk ke gh, dan git bisa mengambil kredensial ujung ke ujung), helper git hilang (inilah yang membuat push ditolak padahal tampilan lama bilang tersambung), sesi berakhir atau token ditolak (perlu masuk ulang), tidak terjangkau (jaringan atau DNS putus), dan lingkungan belum siap. Untuk keadaan helper hilang ada tombol "Perbaiki sambungan" yang memasang ulang git dan gh bila binernya hilang lalu menjalankan ulang penyiapan helper gh, tanpa login ulang.

Catatan jujur: cookie sesi MiMo yang ditanam adalah sesi akun Xiaomi sungguhan dan bisa diekstrak dari APK oleh siapa pun yang mengunduhnya; itu konsekuensi desain "tinggal pakai" yang dipilih sadar, dan cookie itu kedaluwarsa sekitar 16 Desember 2026, sesudah itu MiMo mati di semua pemasangan sampai ada build baru dengan cookie segar. Angka limit konteks keempat model MiMo (128000) adalah asumsi konservatif, bukan angka terverifikasi dari layanan. Soal DNS: penjagaan baru ini menjamin berkas nameserver tidak bergeser dan menambah cadangan, tetapi tidak terbukti sebagai sebab kejadian provider tidak menjawab (EAI_AGAIN) pada 28 November 2026; error itu bisa juga kegagalan jaringan sesaat. Proses lingkungan yang sudah berjalan mungkin baru membaca resolv.conf yang diperbaiki sesudah ia dimulai ulang; proses baru selalu lahir dengan berkas yang benar. Soal GitHub: aplikasi tetap tidak menyimpan token, jadi token yang hilang atau ditolak tetap hanya bisa dipulihkan dengan masuk ulang; tombol perbaiki hanya memulihkan helper dan biner, tidak pernah menjanjikan memulihkan token.

## English summary

Cl0de 0.0.4 is the official release after 0.0.3. It promotes the MiMo provider from the 0.0.4 test build: four Xiaomi MiMo Studio chat models (V2.6 Pro, V2.6 Flash, V2.5 Pro, V2.5) with an embedded session cookie, so every install can use MiMo with no sign-in; that cookie expires around 16 December 2026. The guest environment's DNS is now kept intact: /etc/resolv.conf is re-asserted with three public nameservers (1.1.1.1, 8.8.8.8, 9.9.9.9) before every environment process starts, instead of being written only once at install. The GitHub screen now checks the real connection state inside the environment (healthy, git credential helper missing, session ended or token rejected, unreachable, environment not ready) and offers a repair button that restores the git credential helper and the git/gh binaries without a new sign-in; a lost or rejected token still requires signing in again, because the app never stores the token.

## Pasang

Pasang APK ini menimpa pemasangan sebelumnya, tidak perlu copot pasang, karena sertifikatnya sama dengan release-1 dan semua rilis sesudahnya. Paket com.cl0de.app, versi 0.0.4, versionCode 22. Ukuran dan md5 APK menyusul di catatan rilis GitHub sesudah build selesai, tidak ditulis di berkas ini.
